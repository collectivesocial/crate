# importers

One-time CLI import harness for [crate.social](https://crate.social). Parses content from external sources (RSS feeds, markdown directories, and future adapters like Pocket/Goodreads/Letterboxd), validates records against `social.crate.*` lexicons, and writes them to your ATProto PDS.

**This package is for one-time or manual imports.** Continuous background polling (e.g. RSS every N minutes) lives in `api/workers/` — that's Wash's territory. Use this CLI when you want to run a bulk import on your own schedule.

## Current state

Harness only — the CLI structure and shared utilities are in place, but no adapters are implemented yet. Each subcommand currently prints a `TODO` message and exits cleanly.

## Invocation

```bash
# Requires: node_modules installed (npm install)
# Requires: CRATE_SESSION_FILE set to a valid session JSON (see src/shared/auth.ts)

npm run cli -- rss <feed-url>
npm run cli -- rss <feed-url> --dry-run

npm run cli -- markdown <path/to/notes/dir>
npm run cli -- markdown <path/to/notes/dir> --dry-run

# Help
npm run cli -- --help
npm run cli -- rss --help
npm run cli -- markdown --help
```

## Dry-run mode

Pass `--dry-run` to any subcommand to parse and validate records without writing to the PDS or mutating any local state. Useful for auditing what _would_ be imported.

## Lexicon codegen

After Simon's lexicon JSON files are finalized, generate TypeScript types:

```bash
npm run lexgen
```

This populates `src/lexicon/` from `../../lexicons/` via `@atproto/lex-cli`.
